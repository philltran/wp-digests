## Summary

The Private Content plugin (versions ≤ 9.9.2) contains a critical unauthenticated privilege escalation vulnerability that allows attackers to elevate their capabilities to administrator level without valid credentials. This flaw bypasses WordPress's standard authentication and capability checks, granting full control over the site. The plugin author has not released a patch, so immediate mitigation is required.

## Impact

- **Site owners & administrators**: Running any version up to 9.9.2 exposes the site to complete takeover by unauthenticated attackers. No patch is available from the plugin author.
- **Hosting & platform teams**: Sites using this plugin require immediate isolation, removal, or replacement to prevent compromise.
- **Action required**: Uninstall the plugin immediately or restrict access via server-level rules until a patched version is released. No code changes are needed for other plugins or themes.

## Technical details

The advisory does not disclose specific file paths, functions, or REST endpoints involved in the vulnerability. The escalation occurs through an unauthenticated request that bypasses standard WordPress capability checks, granting administrator-level privileges.
