## Summary

Type Hub contains an unauthenticated arbitrary file upload vulnerability caused by missing file type validation. An attacker can upload arbitrary files to the server, which may enable remote code execution. No patched version is identified in the record.

## Impact

- **Site owners / hosting & platform:** Uninstall or disable Type Hub immediately if present; no known patch is available. If removal is not possible, apply compensating controls such as blocking unauthenticated access to the plugin's upload path and preventing execution of uploaded files.
- **Plugin & theme developers:** Do not rely on Type Hub for file handling; audit any integration that exposes its upload functionality.
- **Headless & REST consumers:** No action required unless the site exposes the vulnerable plugin endpoint to unauthenticated clients.

## Technical details

The vulnerability is an unrestricted upload of a dangerous file type. The record states that file type validation is missing, allowing an unauthenticated attacker to upload arbitrary files. The uploaded files may be used to achieve remote code execution. The source does not name the specific endpoint, handler, function, or file path.
