# Easy Form Builder by WhiteStudio <= 4.0.11 - Unauthenticated Privilege Escalation to Administrator via Password Recovery REST Endpoint

## Summary

The Easy Form Builder plugin contained a critical unauthenticated privilege escalation vulnerability in its password recovery flow. Attackers could exploit a publicly visible session identifier (`sid`) and an unrestricted REST nonce refresh endpoint to reset any WordPress user’s password, including administrators. The vulnerability has been patched in version 4.0.12 by restricting nonce issuance and securing the password recovery token exchange.

## Impact

- **Plugin users (≤4.0.11)**: Must update to 4.0.12 immediately to prevent unauthenticated account takeover.
- **Site owners & developers**: No code changes or migration steps required; the fix is handled internally by the vendor.
- **Hosting & platform teams**: Monitor server logs for exploitation attempts targeting the `Emsfb/v1/` REST routes and unexpected writes to the `wp_emsfb_temp_links` table.

## Technical details

The vulnerability originated from two misconfigurations in the plugin’s REST API layer. First, `Emsfb/v1/nonce/refresh` returned valid WordPress REST nonces to unauthenticated requests, bypassing standard nonce validation. Second, the password recovery flow used the `sid` parameter as a reset token stored in `wp_emsfb_temp_links`, but this value was exposed publicly on rendered form pages. By chaining `Emsfb/v1/forms/message/add` (to trigger recovery) with `Emsfb/v1/forms/recovery/efb_set_password` (to apply the change), an attacker could set an arbitrary password for any known email address. The patch restricts nonce generation to authenticated contexts and validates the `sid` token against the WordPress user database before allowing password modifications.
