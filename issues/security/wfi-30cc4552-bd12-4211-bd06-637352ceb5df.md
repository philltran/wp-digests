## Summary

Drag and Drop Multiple File Upload for Contact Form 7 has an unauthenticated remote code execution vulnerability (CWE-94, code injection) caused by insufficient validation of user-supplied input before it is executed. Any remote attacker can run arbitrary code on the server without logging in. The issue is fixed in 1.3.9.9.

## Impact

**Site owners**
- Any site running Drag and Drop Multiple File Upload for Contact Form 7 below 1.3.9.9 is exposed to unauthenticated RCE (CVSS 9.8). Update to 1.3.9.9 or later immediately.
- Because exploitation requires no authentication, treat sites that ran a vulnerable version as potentially compromised: review for unexpected files, new admin users, modified core/plugin files, and suspicious outbound connections.

**Agencies and hosting or platform teams**
- Audit your fleet for the plugin and its installed version (e.g. `wp plugin list --name=drag-and-drop-multiple-file-upload-contact-form-7 --fields=name,version,status`), and prioritise updates.
- Where immediate patching isn't possible, deactivating the plugin removes the exposure; forms relying on its upload field will stop working.

**Plugin and theme developers**
- No API, hook, or deprecation changes are described in the advisory. The record does not say whether the plugin's settings or behaviour changed in the patched release.
