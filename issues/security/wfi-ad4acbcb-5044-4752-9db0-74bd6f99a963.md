## Summary

Dokan Pro versions up to 5.0.4 contain an unauthenticated privilege escalation vulnerability that allows attackers to elevate their user privileges without valid credentials. The issue was resolved in version 5.0.5, which enforces proper capability checks and access controls. Site owners must update to the patched version to prevent unauthorized access.

## Impact

- **Site owners & agencies**: Update Dokan Pro to 5.0.5 or later immediately. No code modifications or configuration changes are required beyond the standard plugin update.
- **Hosting & platform teams**: Ensure automated patching or update workflows cover Dokan Pro, as this vulnerability is unauthenticated and carries a CVSS 9.8 score.
- **No action required** for sites that have already upgraded or do not use Dokan Pro.

## Technical details

The advisory does not disclose specific functions, file paths, or REST routes involved.
