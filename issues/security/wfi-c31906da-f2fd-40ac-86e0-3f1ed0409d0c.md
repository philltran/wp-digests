## Summary

The SMS Alert plugin (≤3.9.5) contained an unauthenticated privilege escalation vulnerability that allowed attackers to reset arbitrary user passwords, including administrators. The flaw occurred because the plugin updated user details without properly validating the requesting user's identity. Patched in 3.9.6, the fix enforces strict identity verification before processing password reset requests.

## Impact

- **Site owners & administrators**: Update to SMS Alert 3.9.6 immediately to prevent account takeover.
- **Plugin & theme developers**: No action required for standard usage; no code changes or configuration updates needed.
- **Hosting & platform teams**: Ensure automated patching covers this plugin and monitor for exploitation attempts targeting sites with OTP-enabled password resets.

**Note**: The vulnerability only affects sites where OTP verification for password resets is enabled and the target user has a registered phone number.

## Technical details

The vulnerability stems from a missing identity validation check in the plugin's password reset handler. When OTP verification is enabled and a target user has a phone number configured, an unauthenticated request can modify the user's email address and trigger a password reset without proving ownership of existing credentials. The patch in 3.9.6 introduces proper authentication checks before processing user detail updates. The advisory does not expose specific internal file paths or function signatures, but the fix operates at the request-validation layer to block unauthenticated credential modifications.
