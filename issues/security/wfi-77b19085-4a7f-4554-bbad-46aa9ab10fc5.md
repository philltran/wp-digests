# Ultimate Addons for Contact Form 7 3.2.4 - 3.5.50 - Unauthenticated Arbitrary File Upload

- **Source:** Wordfence Intelligence
- **Type:** Vulnerability
- **Published:** 2026-09-17
- **CVE:** [CVE-2026-84750](https://www.cve.org/CVERecord?id=CVE-2026-84750)
- **CVSS:** 9.8 (Critical)
- **CWE:** CWE-434: Unrestricted Upload of File with Dangerous Type
- **Affected:** Ultra Addons for Contact Form 7 (plugin) >= 3.2.4 and <= 3.5.50
- **Patched in:** 3.5.51
- **Researchers:** Jakub Herman
- **Link:** [https://www.wordfence.com/threat-intel/vulnerabilities/id/77b19085-4a7f-4554-bbad-46aa9ab10fc5](https://www.wordfence.com/threat-intel/vulnerabilities/id/77b19085-4a7f-4554-bbad-46aa9ab10fc5)
- **Usefulness:** 5/5

## Summary

The Ultra Addons for Contact Form 7 plugin (titled "Ultimate Addons for Contact Form 7" in the advisory) lacks file type validation in a file upload path, so unauthenticated visitors can upload arbitrary files to the server. Uploading an executable file such as a PHP script may lead to remote code execution. The issue is fixed in 3.5.51.

## Impact

**Site owners**
- Any site running Ultra Addons for Contact Form 7 between 3.2.4 and 3.5.50 inclusive is exposed to unauthenticated attackers. No login or special privileges are required.
- Update to **3.5.51** or later immediately.
- Because the advisory says the flaw may enable remote code execution, sites that ran an affected version on a publicly reachable install should check the uploads directory (and any other directory the plugin writes to) for unexpected files, especially `.php`, `.phtml`, `.phar` or other executable extensions. Treat any such file as a possible compromise.

**Plugin & theme developers / agencies**
- Audit client sites and managed fleets for this plugin and its version.
- If the plugin cannot be updated right away, deactivating it removes the exposure. The advisory does not describe any other workaround.

**Hosting & platform teams**
- Consider blocking PHP execution in upload directories as defense in depth. This is a general hardening measure and is not mentioned in the advisory.

**Headless & REST consumers**
- The record does not say which endpoint or handler is affected, so do not assume headless setups are exempt.

## Technical details

The advisory gives limited detail. The root cause is classified as CWE-434 (Unrestricted Upload of File with Dangerous Type) and described as "missing file type validation". The affected range is >= 3.2.4 and <= 3.5.50, and 3.5.51 is the patched release.

The record does not identify the vulnerable function, hook, upload handler, or AJAX/REST route, and no diff or patch is included, so how 3.5.51 changes the validation is not known from this source. The CVSS score of 9.8 (Critical) reflects network-reachable exploitation without authentication or user interaction.
