## Summary

The Houzez Login Register plugin (versions ≤ 3.3.3) contains a critical unauthenticated privilege escalation vulnerability that allows attackers to elevate their privileges to administrator. No patch has been released, making this a high-severity security issue that requires immediate action from site operators.

## Impact

- **Site owners & agency engineers**: Sites running Houzez Login Register ≤ 3.3.3 are immediately vulnerable to unauthenticated admin takeover.
- **Action required**: No patch is available. Uninstall the plugin or replace it with a maintained alternative. Verify that no custom code or theme integrations rely on its functionality before removal.

## Technical details

The advisory identifies the flaw as CWE-266 (Incorrect Privilege Assignment) but does not disclose specific functions, hooks, or file paths. The vulnerability enables unauthenticated users to bypass capability checks and assume the administrator role. Because no patch exists, mitigation relies entirely on plugin removal or network-level access controls.
