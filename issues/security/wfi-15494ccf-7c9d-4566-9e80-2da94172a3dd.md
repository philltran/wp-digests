## Summary

The Easy Post Submission plugin (≤ 2.3.0) contains a critical missing authorization vulnerability that allows unauthenticated users to modify or unpublish arbitrary posts. The `rbsm_submit_post` AJAX endpoint accepts a `postId` parameter and updates post metadata without verifying user capabilities. Patched in 2.4.0, this flaw enables attackers to alter titles, content, excerpts, taxonomies, and force post statuses to draft.

## Impact

- **Site owners & administrators:** Unauthenticated visitors can edit or unpublish any post on the site. Immediate upgrade to 2.4.0+ is required.
- **Plugin & theme developers:** No direct code changes needed if you are not using the vulnerable plugin, but audit any custom integrations that rely on `rbsm_submit_post`.
- **Hosting & platform teams:** Monitor for anomalous AJAX POST requests to `admin-ajax.php` containing `action=rbsm_submit_post` and `postId` parameters from unauthenticated IPs.
- **Action required:** Update Easy Post Submission to 2.4.0 or later. If the plugin is disabled, the vulnerability is not exploitable.

## Technical details

The vulnerability resides in the `wp_ajax_nopriv_rbsm_submit_post` AJAX handler, which routes to the `create_post()` function. When the `postId` request parameter is present, the function bypasses capability checks and directly updates post fields via WordPress core APIs. An unauthenticated payload can target any post ID, modifying title, content, excerpt, categories, tags, and forcing post status to draft. The fix in 2.4.0 introduces the missing capability verification before processing the `postId` parameter, ensuring only authorized users can modify existing posts.
