# Admin Menu Editor Pro 2.35 - 2.36 - Backdoored Software

- **Source:** Wordfence Intelligence
- **Type:** Vulnerability
- **Published:** 2026-09-15
- **CVSS:** 9.8 (Critical)
- **CWE:** CWE-506: Embedded Malicious Code
- **Affected:** Admin Menu Editor Pro (plugin) >= 2.35 and <= 2.36
- **Link:** [https://www.wordfence.com/threat-intel/vulnerabilities/id/8898bae3-067c-4505-9a96-05b7a08d90c6](https://www.wordfence.com/threat-intel/vulnerabilities/id/8898bae3-067c-4505-9a96-05b7a08d90c6)
- **Usefulness:** 5/5

## Summary

Versions 2.35 and 2.36 of the commercial Admin Menu Editor Pro plugin shipped with an embedded backdoor after the vendor's infrastructure was compromised. The backdoor lets unauthenticated attackers gain access to sites running these versions. Wordfence lists no known patch, and its advisory suggests considering uninstalling the plugin and finding a replacement.

## Impact

**Site owners / agencies**
- Any site running Admin Menu Editor Pro 2.35 or 2.36 should be treated as potentially compromised, not merely vulnerable. Unauthenticated access is possible.
- No patched version is listed. Wordfence advises reviewing the details and applying mitigations based on your risk tolerance, and notes it may be best to uninstall the software and find a replacement.
- Check installed versions across your fleet (e.g. `wp plugin list`) to find affected installs.

**Hosting & platform teams**
- Because the compromise is at the vendor-infrastructure level, this is a supply-chain issue: affected copies came from the vendor's distribution channel, not from a flaw in site configuration.

**Plugin & theme developers**
- Anything that bundles or depends on Admin Menu Editor Pro 2.35–2.36 inherits the exposure.

The advisory does not describe the backdoor's behavior, so the specific indicators of compromise, persistence mechanisms, or cleanup steps are not covered here. Consult the full Wordfence record for further detail.
