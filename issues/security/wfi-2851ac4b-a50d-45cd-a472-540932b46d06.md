- **Usefulness:** 5/5

## Summary

The DS Ad Rotator plugin for WordPress, in all versions up to and including 0.8, lets unauthenticated attackers upload arbitrary files to the server because the upload handler performs no file type validation. Uploading an executable file such as a PHP script can lead to remote code execution. No patched version is available.

## Impact

- **Site owners:**
  - Any site running DS Ad Rotator <= 0.8 is exposed to unauthenticated exploitation. The CVSS score is 9.8 (Critical).
  - There is no known patch. Wordfence recommends uninstalling the plugin and replacing it, or applying mitigations based on your own risk tolerance.
  - Sites that ran the plugin should be checked for unexpected files (especially `.php` files) in upload-related directories and for signs of compromise.
- **Plugin & theme developers / agencies:**
  - Audit client sites and managed fleets for this plugin (`ds-ad-rotator`) and remove or replace it.
  - Where removal is not immediately possible, consider blocking PHP execution in the uploads path at the web server level, or blocking access to the vulnerable endpoint with a WAF rule.
- **Hosting & platform teams:**
  - Consider scanning hosted sites for the plugin and flagging or disabling it.
  - Review logs for unauthenticated POST requests with file uploads to the plugin's handlers.
- **Headless & REST consumers:** The advisory does not say whether a REST route is involved, so no specific guidance can be given.
