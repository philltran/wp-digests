- **Usefulness:** 5/5

## Summary

The Multi Uploader for Gravity Forms plugin (<= 1.1.9) lets unauthenticated attackers upload arbitrary files to the server through its chunked upload handling. The `move_file` function does not sufficiently validate file type when assembling chunks, so dangerous files (such as PHP) can be written to the site, which may lead to remote code execution. No patched version is available.

## Impact

**Site owners**
- Any site running Multi Uploader for Gravity Forms <= 1.1.9 is exposed to unauthenticated exploitation; no login or Gravity Forms account is required.
- No fixed release exists. The advisory recommends assessing risk and considering uninstalling the plugin and replacing it.
- Sites that ran the plugin should review upload directories for unexpected files (especially executable types such as `.php`) and check access logs for chunked-upload requests from unknown clients.

**Plugin & theme developers / agencies**
- Audit client sites and code bases for this plugin. If a Gravity Forms multi-file upload feature is needed, evaluate alternatives.
- Until the plugin is removed, consider blocking PHP execution in the uploads directory at the web server level and applying WAF rules covering the plugin's upload endpoint.

**Hosting & platform teams**
- Consider scanning managed fleets for the plugin slug and flagging versions <= 1.1.9.
- Given the CVSS 9.8 rating and lack of a patch, this is a candidate for virtual patching or forced deactivation.

## Technical details

The source record is a short advisory and does not include a diff or code. What it states:

- The vulnerable code path is the plugin's `move_file` function, reached during chunked file upload handling.
- Root cause is insufficient file type validation (CWE-434, Unrestricted Upload of File with Dangerous Type). Validation is evidently not applied adequately when chunks are combined and moved into place.
- The path is reachable without authentication.
- Consequence: arbitrary files can be placed on the server, which may enable remote code execution.
