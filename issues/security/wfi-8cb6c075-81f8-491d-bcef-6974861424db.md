## Summary

A critical authentication-bypass flaw was fixed in the OTP Login With Phone Number, OTP Verification plugin. The vulnerability allowed unauthenticated attackers to brute-force one-time passwords and bypass OTP verification. This matters because it can lead to unauthorized account access on sites using the plugin. Affected installations should update to the patched release.

## Impact

- **Site owners:** Update the plugin to the patched release; no configuration change is described.
- **Hosting & platform teams:** Patch affected WordPress sites.
- **Plugin & theme developers:** No code change is required unless you depend on the vulnerable plugin's OTP flow.
- **Headless & REST consumers:** No action required unless your integration relies on the plugin's OTP verification.

## Technical details

The advisory identifies the issue as OTP brute force in the plugin, enabling unauthenticated bypass of OTP verification. It does not include a diff, affected endpoints, function names, or code-level remediation details.
