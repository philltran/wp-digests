## Summary

The Frontend Admin plugin for WordPress has an unauthenticated privilege escalation vulnerability in all versions up to and including 3.29.10. An unauthenticated attacker can gain administrator-level access. No patch is known. Sites should treat this as a critical incident and remove or disable the plugin until a fix is available.

## Impact

- **Site owners:** If the plugin is active on any version up to 3.29.10, the site is exposed to administrator-level compromise. No known patch is available; uninstall or disable the plugin and find a replacement.
- **Plugin and theme developers:** Do not depend on or bundle the affected plugin; remove it from builds and staging environments.
- **Hosting and platform teams:** Identify all installs, disable or remove the plugin, and isolate affected sites while investigating.
- **Headless and REST consumers:** No specific REST route or endpoint is disclosed in the record.

## Technical details

The advisory does not disclose the vulnerable function, hook, file, REST route, or code path. It states that the plugin allows an unauthenticated attacker to elevate privileges to administrator in all versions up to and including 3.29.10. No before/after code change is available because no patch is known.
