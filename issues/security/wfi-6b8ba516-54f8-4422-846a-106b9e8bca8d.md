## Summary

The SMS Alert plugin (SMS & OTP for WooCommerce, order notifications, abandoned cart recovery) has a critical authentication bypass in versions before 3.9.8. Unauthenticated attackers can take over other users' accounts, including administrators. The fix shipped in 3.9.8.

## Impact

**Site owners**
- Update to 3.9.8 or later immediately. The flaw is unauthenticated and rated CVSS 9.8, so any site running an affected version with the plugin active is exposed to full account takeover, including administrator accounts.
- Sites using the plugin's OTP or SMS login features should assume the risk is highest, though the advisory does not specify which feature is the entry point.
- If you cannot update right away, deactivate the plugin.
- On sites that ran a vulnerable version, review administrator and customer accounts for unexpected logins, new admin users, password or email changes, and unfamiliar plugin or file changes. The advisory does not describe indicators of compromise, so this is general post-exposure hygiene.

**Plugin & theme developers / agencies**
- Audit client WooCommerce sites for this plugin and its installed version. Also check custom code or integrations that depend on the plugin's OTP/login flow after upgrading.

**Hosting & platform teams**
- Consider identifying sites running the plugin below 3.9.8 for targeted notification or virtual patching. The advisory gives no endpoint or parameter details to write a rule against.

**Headless & REST consumers**
- The advisory does not say whether the vulnerable path is via REST, AJAX, or a form handler, so do not assume headless setups are unaffected.
