## Summary

Advanced Custom Fields: Extended contained an unauthenticated account-takeover flaw: the plugin changed a user's password without first verifying the requester's identity. Any remote attacker could set a new password for an arbitrary account, including an administrator, and then log in as that user. Version 0.9.2.7 fixes it.

## Impact

**Site owners**
- Any site running Advanced Custom Fields: Extended below 0.9.2.7 is exposed to full administrator takeover with no authentication. The CVSS score is 9.8 (Critical).
- Update to 0.9.2.7 or newer immediately.
- Because exploitation would leave a valid administrator login, sites that ran a vulnerable version on the public internet should be checked for compromise. Review administrator accounts for unexpected password resets or new users, check for unfamiliar plugins, themes or modified files, and rotate credentials and salts if anything looks off.

**Plugin & theme developers / agencies**
- Audit client fleets for this plugin and its version, for example with `wp plugin list` across environments.
- No API changes are documented, so there is no migration or code change beyond updating the plugin.

**Hosting & platform teams**
- This is a good candidate for a fleet-wide scan and a virtual patch or WAF rule while updates roll out.
- The advisory does not name the vulnerable endpoint, so any rule would have to be written without knowing the request path.
