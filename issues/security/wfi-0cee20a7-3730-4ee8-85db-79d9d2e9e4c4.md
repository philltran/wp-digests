## Summary

The Membership For WooCommerce plugin contained an unauthenticated arbitrary file deletion vulnerability in versions up to 3.1.0. Insufficient path validation in the `[function-name]` function allowed remote attackers to delete arbitrary files on the server, which could be leveraged for remote code execution by targeting critical files like `wp-config.php`. The issue was resolved in version 3.1.1.

## Impact

- **Site owners & administrators**: Update to version 3.1.1 immediately. The vulnerability is unauthenticated and critical.
- **Hosting & platform teams**: Monitor for unexpected file deletions or modifications to core WordPress files (`wp-config.php`, `wp-content/`) on affected installations.
- **No action required** beyond patching; no configuration changes or migrations are needed.

## Technical details

The advisory identifies insufficient file path validation in the `[function-name]` function as the root cause. The flaw allows unauthenticated HTTP requests to bypass path sanitization, enabling arbitrary file deletion on the server filesystem. Patching in 3.1.1 introduces proper path validation to restrict deletion operations to intended directories. (Note: The exact function name was redacted as `[function-name]` in the source advisory.)
