## Summary

The `user_filter` function in Spreadsheet Price Changer for WooCommerce and WP E-commerce – Light (≤ 2.4.37) lacks authorization checks, allowing unauthenticated users to create new administrator accounts. This missing authorization enables immediate privilege escalation without requiring any credentials. The plugin author has not released a patch, so the only mitigation is to remove the plugin or switch to an alternative.

## Impact

- **Site owners & administrators**: Unauthenticated attackers can create admin accounts, potentially leading to full site compromise.
- **Plugin & theme developers**: No direct API changes, but the vulnerability highlights a common oversight in unauthenticated callback handling.
- **Hosting & platform teams**: Should monitor for unauthorized admin account creation and consider blocking the affected plugin on managed WordPress hosts.
- **Required action**: Immediate removal or replacement of the plugin is recommended, as no patch exists.

## Technical details

The vulnerability resides in the `user_filter` function, which processes user creation requests without verifying authentication or authorization. Because the function is exposed to unauthenticated requests, an attacker can send a crafted request to register a new user with the `administrator` role. No code diff or patch is available from the maintainer, and the function remains unguarded in all versions ≤ 2.4.37.
