# miniOrange OTP Login, Verification and SMS Notifications <= 5.5.1 - Authentication Bypass to Administrator Account Takeover via 'username_b' Parameter

## Summary

The miniOrange OTP Login, Verification and SMS Notifications plugin was patched in version 5.5.2 to resolve a critical authentication bypass that allowed unauthenticated attackers to hijack administrator accounts. The flaw originated in `um_reset_password_process_hook()`, which skipped server-side OTP validation and accepted an attacker-controlled `username_b` parameter to generate password-reset URLs for arbitrary users. Updating to 5.5.2 is required to restore proper session binding and role restrictions during the reset flow.

## Impact

- **Site owners & plugin administrators**: Update to version 5.5.2 immediately. The vulnerability only triggers when the Ultimate Member Password Reset Form integration is active and phone-only reset is disabled.
- **Hosting & platform teams**: Monitor server logs for requests to the Ultimate Member password reset endpoint containing a `username_b` parameter, which may indicate exploitation attempts.
- **No action required** for sites that do not use the miniOrange plugin or have the Ultimate Member integration disabled.

## Technical details

The vulnerability resided in `um_reset_password_process_hook()`, which previously performed no server-side verification that the OTP validation step was completed. It relied solely on a `form_nonce` emitted to unauthenticated visitors via the `moumprvar` JavaScript object on the Ultimate Member password reset page, while accepting an attacker-controlled `username_b` parameter to target any WordPress user without role restriction or binding to a validated OTP session. The patched version enforces server-side OTP session validation before processing the reset request, binds the action to the validated session, and restricts the `username_b` parameter to prevent arbitrary user targeting. Successful exploitation previously returned a 302 `Location` header containing a password-reset URL for the targeted account.
