# Lenxel WP <= 1.0.31 - Unauthenticated Privilege Escalation via Account Takeover

- **Affected:** Lenxel WP (theme) <= 1.0.31

- **Usefulness:** 5/5

## Summary

The Lenxel WP WordPress theme is vulnerable to unauthenticated privilege escalation through account takeover in versions up to and including 1.0.31. The theme does not properly validate a user's identity before allowing updates to account details, including password changes. An unauthenticated attacker can change an arbitrary user's password, including an administrator, and then log in as that user. No patch is listed, so the practical response is to remove or replace the theme and remediate affected accounts.

## Impact

- **Site owners / hosting & platform**: Sites using the affected theme should treat this as an active compromise risk. Uninstall or replace the theme, audit user accounts, force password resets, review logs for unauthorized account changes, and restrict access to theme endpoints until the theme is removed.
- **Plugin & theme developers**: If building account-update functionality, require authentication, verify the current password or use appropriate capability and nonce checks, and never expose password updates without identity validation.
- **Headless & REST consumers**: No direct API change is described, but any integration relying on the theme's account endpoints should be disabled or protected while the theme is present.

## Technical details

The advisory describes the flaw as an unverified password change: the theme permits updating user details such as a password without validating the requester's identity. The record does not name the specific file, function, hook, REST route, or option involved. The practical behavior is that an unauthenticated request can set a new password for an arbitrary user account, enabling account takeover and privilege escalation if an administrator account is targeted.
