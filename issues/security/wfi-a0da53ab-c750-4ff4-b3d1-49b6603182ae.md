# Private Feed Key <= 0.1 - Authentication Bypass

- **Source:** Wordfence Intelligence
- **Type:** Vulnerability
- **Published:** 2026-09-15
- **CVE:** [CVE-2026-86707](https://www.cve.org/CVERecord?id=CVE-2026-86707)
- **CVSS:** 9.8 (Critical)
- **CWE:** CWE-288: Authentication Bypass Using an Alternate Path or Channel
- **Affected:** Private Feed Key (plugin) <= 0.1
- **Researchers:** Naoki Kawahigashi
- **Link:** [https://www.wordfence.com/threat-intel/vulnerabilities/id/a0da53ab-c750-4ff4-b3d1-49b6603182ae](https://www.wordfence.com/threat-intel/vulnerabilities/id/a0da53ab-c750-4ff4-b3d1-49b6603182ae)
- **Usefulness:** 4/5

## Summary

The Private Feed Key plugin, in all versions up to and including 0.1, contains an authentication bypass that lets unauthenticated attackers log in as arbitrary users, including administrators. The advisory classifies it as CWE-288 (authentication via an alternate path or channel). No patched version exists.

## Impact

**Site owners**
- Any site running Private Feed Key <= 0.1 is exposed to unauthenticated full account takeover, including administrator accounts. With no privileges or user interaction required, this amounts to full site compromise.
- No patch is available. The advisory recommends uninstalling the plugin and finding a replacement, or applying mitigations based on your risk tolerance.
- If the plugin has been active on a site, review it for compromise: check for unexpected administrator accounts, recently modified users, newly installed plugins or themes, and unfamiliar logins.

**Plugin & theme developers / agencies**
- Audit client sites for this plugin (e.g. `wp plugin list | grep private-feed-key`) and remove it.
- If the plugin was used to protect RSS/feed access, plan for a replacement approach.

**Hosting & platform**
- Consider flagging or blocking the plugin fleet-wide, since there is no fixed version to upgrade to.

**Headless & REST consumers**
- The advisory does not describe the specific entry point, so do not assume that headless or REST-only setups are unaffected.

## Technical details

The advisory record gives no code-level detail: no vulnerable function, hook, endpoint, or parameter is named. All that is stated is that versions <= 0.1 allow unauthenticated attackers to bypass authentication and log in as other users, including administrators. The CWE-288 classification points to an alternate path or channel that skips the normal authentication checks, but the specific mechanism is not described in the source, so it should not be inferred. The CVSS score is 9.8 (Critical). Wordfence lists no patched version.
