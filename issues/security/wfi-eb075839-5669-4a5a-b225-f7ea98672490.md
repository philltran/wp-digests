# Newspapers X 1.0.46 - 1.0.48 - Backdoor

- **Source:** Wordfence Intelligence
- **Type:** Vulnerability
- **Published:** 2026-08-28
- **CVE:** [CVE-2026-81779](https://www.cve.org/CVERecord?id=CVE-2026-81779)
- **CVSS:** 9.8 (Critical)
- **CWE:** CWE-506: Embedded Malicious Code
- **Affected:** Newspapers X (theme) >= 1.0.46 and <= 1.0.48
- **Patched in:** 1.0.49
- **Researchers:** ashv4ni
- **Link:** [https://www.wordfence.com/threat-intel/vulnerabilities/id/eb075839-5669-4a5a-b225-f7ea98672490](https://www.wordfence.com/threat-intel/vulnerabilities/id/eb075839-5669-4a5a-b225-f7ea98672490)
- **Usefulness:** 5/5

## Summary

Versions 1.0.46 through 1.0.48 of the Newspapers X theme shipped with embedded malicious code, a backdoor that lets unauthenticated attackers achieve remote code execution on the site. The issue is fixed in 1.0.49. Any site running an affected version should be treated as potentially compromised, not merely vulnerable.

## Impact

**Site owners**
- Sites running Newspapers X 1.0.46, 1.0.47, or 1.0.48 are exposed to unauthenticated remote code execution (CVSS 9.8).
- Updating to 1.0.49 removes the backdoor from the theme files, but it does not undo anything an attacker already did. Assume compromise if an affected version was ever active or present on disk.
- Post-update, check for signs of prior exploitation: unfamiliar admin users, modified or added PHP files (in the theme, `wp-content/uploads`, or elsewhere), unexpected scheduled events, and altered options. Rotate credentials, salts, and API keys if compromise is suspected.

**Agencies & hosting/platform teams**
- Inventory managed sites for the Newspapers X theme, including inactive copies and child-theme parents, and check installed versions.
- Because this is embedded malicious code rather than a coding flaw, the affected theme files should be replaced with a clean copy of 1.0.49 rather than patched in place.

**Plugin & theme developers / REST consumers**
- No API changes. No code changes required beyond updating the theme.

## Technical details

The source record does not describe the backdoor's mechanism, entry point, or trigger. It classifies the issue as CWE-506 (Embedded Malicious Code) and states only that the theme contains a backdoor in 1.0.46-1.0.48 enabling unauthenticated RCE. No affected files, functions, hooks, or request parameters are given, so none are listed here. The fix is delivered in theme version 1.0.49.
