# Social Login & Sharing buttons with Analytics By SoClever <= 1.2.0 - Authentication Bypass to Administrator

- **Affected:** Social Login & Sharing buttons with Analytics By SoClever (plugin) <= 1.2.0
- **Researchers:** Khaled Alenazi

- **Usefulness:** 5/5

## Summary

The Social Login & Sharing buttons with Analytics By SoClever plugin (<= 1.2.0) contains an authentication bypass that lets unauthenticated attackers log in as arbitrary existing users, including administrators. The advisory classifies it as CWE-288 (authentication via an alternate path or channel) and rates it CVSS 9.8. No patched version is available.

## Impact

**Site owners**
- Any site running version 1.2.0 or earlier is exposed to unauthenticated takeover of any account, including administrator accounts. Administrator access typically allows arbitrary PHP execution through plugin/theme upload or the file editor.
- There is no known patch. The advisory recommends assessing risk and notes it may be best to uninstall the plugin and find a replacement.
- Deactivate and remove the plugin. If it was active on a public site, treat the site as potentially compromised: review administrator and other privileged accounts, recently created users, installed plugins/themes, and modified files, and rotate credentials and sessions/salts.

**Plugin & theme developers / agencies**
- Audit client sites for this plugin (slug not stated in the advisory, so search by name) and plan a replacement social-login solution.

**Hosting & platform teams**
- Consider a fleet-wide scan for the plugin and blocking or virtual-patching where your WAF supports it. The advisory does not describe the vulnerable endpoint, so any rule would need to be built from your own analysis.

**Headless & REST consumers**
- The advisory does not say whether a REST route is involved. If the plugin is installed, assume any login path on the site is affected.

## Technical details

The advisory gives no code-level detail. It states only that all versions up to and including 1.2.0 are vulnerable to authentication bypass, allowing unauthenticated attackers to log in as other users such as administrators. The CWE-288 classification points to a login path that does not enforce the normal authentication checks, which is plausible for a social-login flow, but the advisory does not identify the function, hook, endpoint, or parameter involved. The record does not state the exploitation conditions, so none should be assumed. No fixed version exists, so there is no diff or patch to describe.
