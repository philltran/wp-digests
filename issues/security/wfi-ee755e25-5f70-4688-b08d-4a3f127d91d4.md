## Summary

The Kirki plugin (Freeform Page Builder, Website Builder & Customizer) has a critical unauthenticated remote code execution vulnerability. User-supplied input is executed on the server without sufficient validation. Version 6.2.1 contains the fix.

## Impact

**Site owners**
- Any site running Kirki below 6.2.1 is exposed to unauthenticated attackers who can execute arbitrary code on the server. No login or account is required to exploit it.
- Update to 6.2.1 or later immediately. If you cannot update right away, deactivate the plugin until you can.
- Sites that were exposed for any period should be checked for signs of compromise, such as unexpected files, new admin users, or modified plugins and themes.

**Plugin & theme developers / agencies**
- Audit client sites and any themes or plugins that bundle or depend on Kirki for the affected version range.
- The record names no deprecations, removed APIs, or migration steps.

**Hosting & platform teams**
- Consider scanning managed fleets for Kirki < 6.2.1 and prioritizing patching or temporary WAF rules.

## Technical details

The advisory is classified as CWE-94 (Improper Control of Generation of Code) with a CVSS of 9.8. It states that user-supplied input is insufficiently validated before it is executed, and that unauthenticated attackers can trigger this.

The record does not identify the vulnerable file, function, hook, AJAX action, or REST route, and it includes no diff or patch description. Details of the fix are therefore not available from this source. The remediation is to upgrade to 6.2.1 or a newer patched release.

The advisory text says "all versions up to 6.2.1" while the affected range and patched version are listed as `< 6.2.1` and 6.2.1 respectively. Treat 6.2.1 as the first fixed version.
