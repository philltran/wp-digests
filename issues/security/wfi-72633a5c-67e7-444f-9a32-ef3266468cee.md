## Summary

The MailOptin plugin (versions ≤ 1.2.77.3) contained an unauthenticated privilege escalation vulnerability that allowed attackers to elevate their user roles without credentials. The issue was resolved in version 1.2.78.0, which enforces proper capability checks to prevent unauthorized role changes.

## Impact

- **Site owners & administrators**: Must update the MailOptin plugin to 1.2.78.0 or later immediately to prevent unauthorized privilege escalation.
- **Plugin & theme developers**: No direct code changes required; the fix is contained within the plugin itself.
- **Hosting & platform teams**: Ensure automated update policies flag this plugin for immediate patching.
- **No action required** for sites not using the MailOptin plugin.

## Technical details

The advisory does not disclose specific file paths, function names, or REST endpoints involved in the vulnerability. The patch in 1.2.78.0 addresses the incorrect privilege assignment (CWE-266) by validating user capabilities before processing role-elevation requests. Developers relying on the plugin's internal role-management logic should verify that their integrations do not depend on the previously bypassed checks.
