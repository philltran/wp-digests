## Summary

The Simple Coherent Form plugin (≤ 2.4.13) contains a critical unauthenticated arbitrary file deletion vulnerability (CVE-2026-14487) that allows attackers to bypass authorization checks and delete arbitrary server files. The flaw stems from insufficient path validation in `removeUploadDir`, combined with a publicly accessible nonce endpoint and a forgeable offline hash check due to a hardcoded salt. This bypass can lead to remote code execution if critical files like `wp-config.php` are removed.

## Impact

- **Plugin users**: Sites running Simple Coherent Form ≤ 2.4.13 are immediately vulnerable to unauthenticated file deletion. No patch is currently available; affected operators should uninstall the plugin or replace it with a maintained alternative.
- **Other developers/platforms**: No action required. The vulnerability is isolated to the affected plugin and does not impact WordPress core or other ecosystem components.

## Technical details

The vulnerability resides in the `removeUploadDir` function, which lacks proper sanitization of the `id` parameter, enabling path traversal (CWE-22). Authorization is bypassed through two mechanisms: the `scf_get_id_upload` endpoint issues a valid `scf_upload_file_removal` nonce to any unauthenticated request, and the subsequent hash verification relies on a hardcoded salt embedded in the plugin source, making it forgeable offline. Without a patch, the only mitigation is removing the plugin entirely.
