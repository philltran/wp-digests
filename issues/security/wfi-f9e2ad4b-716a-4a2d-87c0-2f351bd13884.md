# Customer Support Ticket System & Helpdesk <= 6.0.5 - Unauthenticated Code Injection via 'path' Parameter

## Summary

The Customer Support Ticket System & Helpdesk plugin contained an unauthenticated code injection vulnerability in versions up to 6.0.5. Attackers could exploit the `path` parameter to invoke arbitrary PHP functions due to insufficient validation of dynamic function calls. The issue was resolved in version 6.0.6 by validating the parameter before execution, eliminating the remote code execution risk.

## Impact

- **Plugin users & site owners:** Must update to version 6.0.6 or later immediately. No code changes or configuration adjustments are required.
- **Security & hosting teams:** Monitor server logs for unauthenticated requests targeting the `path` parameter on pages that render the `[emd_form]` shortcode, as the required nonce was publicly exposed via `wp_localize_script`.
- **Developers:** No API changes or migration steps are needed; the fix is contained within the plugin update.

## Technical details

The vulnerability stemmed from dynamic function invocation using the `path` parameter without sufficient validation. The `[emd_form]` shortcode triggered `wp_localize_script`, publicly emitting the required nonce and allowing unauthenticated access. The 6.0.6 patch validates and sanitizes the `path` parameter before execution, blocking arbitrary PHP function calls.

## Contribution

The advisory record carries no detailed discussion or alternative remediation approaches; the vulnerability was reported by researcher theviper17y and patched in version 6.0.6.
