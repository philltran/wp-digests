- **Type:** Vulnerability

- **Affected:** Login with QR (plugin) <= 1.0.0
- **Researchers:** Naoki Kawahigashi

- **Usefulness:** 5/5

## Summary

The Login with QR plugin for WordPress has an unauthenticated authentication bypass in all versions up to and including 1.0.0. An attacker can log in as any user, including administrators, without valid credentials. No patched version is available.

## Impact

**Site owners**
- Any site running Login with QR <= 1.0.0 is exposed to full account takeover, including administrator accounts, by unauthenticated remote attackers.
- No patch exists. Wordfence recommends reviewing the details and applying mitigations based on your risk tolerance, and suggests it may be best to uninstall the plugin and find a replacement.
- If the plugin was active, treat the site as potentially compromised: audit administrator and other privileged accounts, recently created users, installed plugins/themes, and file changes.

**Plugin & theme developers / agencies**
- Inventory client sites for this plugin (for example with `wp plugin list`) and deactivate and remove it where found.
- If QR-based login is a business requirement, evaluate an alternative plugin rather than waiting for a fix.

**Hosting & platform teams**
- Consider a fleet-wide search for the plugin and blocking or virtual-patching where your WAF tooling allows. The upstream record does not describe the vulnerable endpoint, so request-level rules cannot be derived from it.

**Headless & REST consumers**
- The record does not say which entry point is affected, so do not assume a headless setup is unaffected if the plugin is installed.

## Technical details

The upstream record gives limited detail. It classifies the flaw as CWE-288 (Authentication Bypass Using an Alternate Path or Channel) with a CVSS of 9.8, which implies a network-reachable path that requires no privileges or user interaction.
