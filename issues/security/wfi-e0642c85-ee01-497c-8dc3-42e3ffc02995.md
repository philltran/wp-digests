## Summary

The Jawn WordPress theme, in all versions up to and including 1.4.2, contains an unauthenticated privilege escalation flaw that lets a remote attacker elevate themselves to administrator. The advisory classifies it as incorrect privilege assignment. No patched version is available.

## Impact

- **Site owners:**
  - Any site running Jawn <= 1.4.2 is exposed to full site takeover by unauthenticated visitors. An attacker with administrator rights can install plugins, edit code, and create or modify users.
  - There is no vendor fix. The advisory suggests weighing mitigations against your risk tolerance and notes that uninstalling the theme and switching to a replacement may be the best option.
  - Audit `wp_users` and `wp_usermeta` for unexpected administrator accounts, and review recently installed plugins and modified theme or plugin files for signs of compromise.
- **Plugin & theme developers / agencies:**
  - Inventory client sites for the `jawn` theme, including inactive installs and child themes that depend on it.
  - Plan a migration to a different theme. Because no patch exists, upgrading is not an available remediation.
- **Hosting & platform teams:**
  - Consider flagging or blocking the theme fleet-wide. Virtual patching or WAF rules may help, but the source record gives no exploit details to base a rule on.
- **Headless & REST consumers:**
  - The record does not say which entry point is vulnerable, so it is not possible to say whether REST or AJAX routes are involved.
