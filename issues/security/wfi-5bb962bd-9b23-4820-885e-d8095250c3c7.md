## Summary

Printcart Web to Print Product Designer for WooCommerce versions ≤2.5.2 contain a critical unauthenticated arbitrary file deletion vulnerability (CVE-2026-9725). The flaw stems from insufficient path validation in the `store_design_data()` function, which accepts a user-supplied `nbd_item_key` parameter and passes it directly to `Nbdesigner_IO::delete_folder()` and `rename()` without blocking path traversal sequences. Attackers can bypass the AJAX nonce requirement by fetching it through the `nbd_check_use_logged_in` endpoint, enabling them to delete arbitrary server files and potentially achieve remote code execution. Site owners must update to version 2.5.3 or later immediately.

## Impact

- **Plugin users (site owners & agencies):** Sites running Printcart Web to Print Product Designer for WooCommerce ≤2.5.2 are immediately vulnerable to unauthenticated file deletion. Update to ≥2.5.3 to patch.
- **Hosting & platform teams:** Monitor for anomalous `rename()` or filesystem deletion activity originating from WooCommerce AJAX endpoints. Consider blocking or rate-limiting the `nbd_check_use_logged_in` endpoint until patched.
- **No action required** for sites not using this plugin.

## Technical details

The vulnerability resides in the `store_design_data()` function, which constructs a filesystem path from the `nbd_item_key` POST parameter. The value is sanitized only with `sanitize_text_field()`, which does not strip path traversal sequences, and is passed directly to `Nbdesigner_IO::delete_folder()` and PHP's `rename()` function, enabling arbitrary file deletion. The nonce protecting the `nbd_save_customer_design` AJAX action is bypassable because the `nbd_check_use_logged_in` endpoint exposes it to unauthenticated requests. The patch resolves the path validation gap and restricts nonce exposure to authenticated contexts.
