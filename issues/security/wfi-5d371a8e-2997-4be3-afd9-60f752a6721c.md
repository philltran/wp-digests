# OMGF Pro <= 5.2.6 - Unauthenticated Arbitrary File Upload via @import URL Reflection

## Summary

The OMGF Pro plugin has been patched to resolve a critical unauthenticated arbitrary file upload vulnerability (CVE-2026-57700) that allowed remote code execution. The flaw existed in the `ExternalStylesheets::optimize()` method, which previously fetched external CSS `@import` URLs and wrote their contents directly to the uploads directory without validating file types, checking MIME types, or verifying user capabilities. Updating to version 5.2.7 or later is required to secure affected sites.

## Impact

- **Site owners & administrators:** Update OMGF Pro to v5.2.7 immediately. Sites running v5.2.6 or earlier are vulnerable to unauthenticated remote code execution.
- **Hosting & platform teams:** Monitor for suspicious PHP file uploads in the `wp-content/uploads` directory and ensure the plugin is patched across all managed instances.
- **No action required** for sites that have already updated or do not use OMGF Pro.

## Technical details

The vulnerability resided in `ExternalStylesheets::optimize()`, which processed the `omgf_optimize` and `omgf_pro_auto_config` GET parameters without nonce or capability checks. The method parsed rendered HTML for `@import` directives, resolved them via `wp_remote_get()`, and saved the response body to disk using `file_put_contents()` with a path constructed directly from the attacker-controlled URL host and path. The patch resolves the issue by enforcing a file-extension allowlist, adding MIME type verification, and gating the optimization pipeline behind a capability/nonce check before any remote fetch or disk write occurs.
