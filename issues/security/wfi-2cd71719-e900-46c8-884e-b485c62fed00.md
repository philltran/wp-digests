- **Usefulness:** 5/5

## Summary

The ManageWP Worker plugin, which lets the ManageWP dashboard remotely administer a site, has an authentication bypass in all versions before 4.9.37. An unauthenticated attacker can log in as another user, including an administrator. The fix ships in 4.9.37.

## Impact

**Site owners / agencies**
- Any site running ManageWP Worker < 4.9.37 is exposed to unauthenticated administrator takeover (CVSS 9.8, Critical). Update to 4.9.37 or later immediately.
- Sites that have the plugin installed but no longer actively use ManageWP are equally affected. Update or remove the plugin.
- Because the flaw allows login as an administrator, sites that ran a vulnerable version on the public internet should be reviewed for compromise: unexpected admin users, changed passwords, newly installed or modified plugins/themes, and unfamiliar files.

**Plugin & theme developers / platform teams**
- Fleet operators should inventory installed Worker versions (for example, `wp plugin list --name=worker`) and prioritize patching. Managed hosts may want to consider a virtual patch or block rule until updates land.

**Headless & REST consumers**
- No specific information is given about the vulnerable entry point, so do not assume REST or non-REST exposure either way.

No code changes are needed beyond updating the plugin.
