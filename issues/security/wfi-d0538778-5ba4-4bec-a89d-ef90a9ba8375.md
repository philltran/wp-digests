# Bricksforge <= 3.1.8.6 - Unauthenticated Privilege Escalation via Pro Forms fieldIds Parameter

## Summary

The Bricksforge plugin contains a critical unauthenticated privilege escalation vulnerability in versions up to 3.1.8.6. Improper validation of the `fieldIds` parameter in the Pro Forms registration action allows attackers to inject arbitrary field IDs into a trusted whitelist. This bypasses intended access controls, enabling unauthenticated users to register new administrator accounts on sites that expose a public Bricksforge Pro Forms element configured with the User Registration action.

## Impact

- **Site owners & administrators:** Immediate risk of unauthorized administrator account creation if the site uses Bricksforge Pro Forms with a public User Registration action. Requires updating the plugin to version 3.1.8.7 or later.
- **Plugin & theme developers:** No direct code changes required for third-party developers, but agencies managing client sites must audit for Bricksforge installations and apply the patch immediately.
- **Hosting & platform teams:** Monitor for exploitation attempts targeting the Pro Forms registration endpoint and ensure automated patching workflows prioritize this update.
- **No action required** for sites that do not use Bricksforge or have not enabled the Pro Forms User Registration action.

## Technical details

The vulnerability stems from insufficient validation of the `fieldIds` parameter passed during the Pro Forms registration action. The plugin fails to sanitize or verify attacker-supplied field IDs before appending them to an internal trusted form-field whitelist. When a site has a publicly accessible Bricksforge Pro Forms element configured with the User Registration action, an unauthenticated attacker can craft a request that injects privileged field identifiers into this whitelist, effectively bypassing registration restrictions and triggering administrator account creation. Patched in 3.1.8.7 by enforcing strict validation on the `fieldIds` parameter before whitelist population.
