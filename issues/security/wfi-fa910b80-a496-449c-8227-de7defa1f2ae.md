## Summary

The Total Donations plugin for WordPress allows unauthenticated attackers to elevate their privileges to administrator in all versions up to and including 2.0.5. The advisory classifies the flaw as improper privilege management and rates it critical. No patched version is available.

## Impact

**Site owners**
- Any site running Total Donations <= 2.0.5 is exposed to full site takeover by an unauthenticated remote attacker, since the result is administrator access.
- There is no known patch. The advisory recommends mitigations based on your risk tolerance and suggests that uninstalling the plugin and finding a replacement may be best.
- If the plugin is not essential, deactivate and remove it. If you have to keep it, treat the site as high risk: audit the user list for unexpected administrator accounts, review recent user-role changes, and rotate credentials and salts if compromise is suspected.

**Plugin & theme developers / agencies**
- Inventory client sites for this plugin and plan a replacement or removal, because no fixed release exists to upgrade to.

**Hosting & platform teams**
- Consider scanning managed fleets for the plugin slug and flagging or blocking affected installs.
- Check for administrator accounts created since the advisory's publication date.
