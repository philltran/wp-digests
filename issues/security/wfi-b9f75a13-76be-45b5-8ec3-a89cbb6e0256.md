## Summary

RegistrationMagic (custom registration forms, user registration, payments, and login plugin) versions up to and including 6.0.9.8 contain an authentication bypass that lets unauthenticated attackers get past authentication. The flaw is rated critical (CVSS 9.8) and is fixed in 6.0.9.9. The advisory does not describe the vulnerable code path or what access the bypass grants.

## Impact

**Site owners**
- Any site running RegistrationMagic <= 6.0.9.8 is exposed to unauthenticated attackers. Update to 6.0.9.9 or later as soon as possible.
- The advisory does not say what the bypass yields (e.g. login as an arbitrary user or administrator). Because of the 9.8 score and the CWE-288 classification, treat it as potential account takeover: after patching, review recently created or modified users, administrator accounts, and active sessions for anything unexpected.

**Plugin & theme developers / agencies**
- Audit client sites and managed fleets for the plugin and its installed version; sites with auto-updates disabled or pinned versions are most likely to be behind.
- No API, hook, or configuration changes are documented in the advisory, so there is no code migration; the fix is the plugin update.

**Hosting & platform teams**
- Consider prioritizing this in patch rollouts and checking access logs for suspicious unauthenticated requests to the plugin's endpoints, though the advisory does not identify which endpoints are involved.
