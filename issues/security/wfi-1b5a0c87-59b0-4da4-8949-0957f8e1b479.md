## Summary

EventON versions up to 5.0.11 contain an unauthenticated blind SQL injection vulnerability triggered through the WordPress `search` parameter. The flaw stems from insufficient input escaping and missing query preparation, allowing attackers to extract database contents when the "Enable additional search queries" setting is active and at least one event is published. No official patch has been released, so site operators must rely on configuration changes or plugin removal to mitigate the risk.

## Impact

- **Site owners & administrators**: Immediate configuration change required. Disable the "Enable additional search queries" setting in EventON, or uninstall the plugin until a patched version is released.
- **Hosting & platform teams**: Deploy WAF rules to block SQL injection payloads targeting the `search` parameter on affected sites.
- **Plugin & theme developers**: No direct code changes required, but audit any custom search integrations for similar unprepared query patterns.

## Technical details

The vulnerability resides in how EventON processes the WordPress `search` query variable. When the "Enable additional search queries" setting is enabled, the plugin constructs a database query without properly escaping or preparing the `search` parameter, resulting in a blind SQL injection. Attackers can append arbitrary SQL statements to extract sensitive data. Exploitation requires at least one published event to trigger the vulnerable code path. As of publication, no patched version exists; mitigation involves disabling the additional search feature or removing the plugin.
