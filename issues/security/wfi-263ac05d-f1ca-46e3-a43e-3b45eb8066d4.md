# Forminator Forms <= 1.56.1 - Unauthenticated Arbitrary File Upload via Forged Upload Field Configuration

## Summary

Forminator Forms versions up to 1.56.1 allowed unauthenticated arbitrary file upload through the `handle_file_upload` function. The plugin's dangerous-extension blocklist used exact-key matching that could be bypassed with pipe-alternative MIME type keys, and a public submission handler accepted attacker-controlled upload field configuration from a forged Select field value. This could let an attacker upload files that may be executable and achieve remote code execution. The issue is fixed in 1.56.2.

## Impact

- **Site owners / hosting & platform:** Update Forminator Forms to 1.56.2 or later; this is a critical unauthenticated upload issue with RCE potential.
- **Plugin & theme developers:** No developer-facing API change is described in the advisory.
- **Headless & REST consumers:** No action is described beyond updating the plugin.

## Technical details

The vulnerable code path is `handle_file_upload`. The dangerous-extension blocklist performs exact-key matching on MIME type keys, and pipe-alternative MIME type keys bypass that check. A public submission handler trusts attacker-controlled upload field configuration injected via a forged Select field value. The combination allows unauthenticated attackers to upload files that may be executable, enabling remote code execution.
