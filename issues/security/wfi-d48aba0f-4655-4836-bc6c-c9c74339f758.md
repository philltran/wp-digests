## Summary

The Choose User Role at Registration for WooCommerce plugin, in versions up to and including 1.3.2, does not sufficiently restrict which capabilities or roles a user can assign to themselves. An unauthenticated attacker can use this to escalate privileges beyond those intended for their role. The issue is fixed in 1.3.3.

## Impact

**Site owners**
- Any WooCommerce site running Choose User Role at Registration for WooCommerce <= 1.3.2 is exposed to unauthenticated privilege escalation, rated CVSS 9.8 (Critical).
- Update to **1.3.3** or later. If you cannot update immediately, deactivate the plugin.
- Because the flaw is exploitable without authentication, audit existing accounts for unexpected elevated roles (e.g. `administrator`, `shop_manager`) created since the plugin was installed.

**Plugin & theme developers / agencies**
- Check client sites and managed fleets for this plugin and its version.
- If your code or theme relies on the role-selection field at registration, retest registration flows after upgrading to 1.3.3, since the patch may change which roles can be chosen.

**Hosting & platform teams**
- Consider prioritising this in vulnerability scanning and virtual-patching rules, given the critical score and no authentication requirement.

**Headless & REST consumers**
- The advisory does not say which entry point (form handler, REST, or AJAX) is affected, so do not assume headless setups are unaffected.

## Technical details

The advisory is brief. It attributes the flaw to "insufficient restriction on the capabilities a user may grant themselves" (CWE-269, Improper Privilege Management). The likely shape is that the role chosen at registration is not validated against an allow-list, but the record does not confirm this.

The advisory does not name the vulnerable function, hook, request parameter, or file, and no diff or patch details are provided. The fix ships in version 1.3.3; review the plugin changelog or the 1.3.2→1.3.3 diff on the WordPress.org plugin repository for the exact change.
