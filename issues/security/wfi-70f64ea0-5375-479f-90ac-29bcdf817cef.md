## Summary

The Advanced Responsive Video Embedder plugin (v10.8.7) contains a hardcoded backdoor that allows unauthenticated users to bypass WordPress authentication and assume any existing administrator role. The vulnerability stems from the `_arve_uc_init()` function, which runs on the `init` hook at priority 1 and validates a static SHA-256 hash against the `_wplogin` (or `_wpm`) request parameter. Because the hash is embedded directly in the plugin source, attackers can supply the known token to gain full administrative control without credentials.

## Impact

- **Site owners & administrators:** Unauthenticated attackers can assume any existing administrator role. No vendor patch is available.
- **Plugin & theme developers:** No code migration is possible; the backdoor is hardcoded in the plugin's core logic.
- **Hosting & platform teams:** Sites running v10.8.7 are immediately exploitable. Uninstall or disable the plugin and migrate to a maintained alternative.

## Technical details

The `_arve_uc_init()` function is attached to the `init` action at priority `1`. It extracts the `_wplogin` parameter (falling back to `_wpm`), compares the value against a static SHA-256 hash embedded in the plugin source, and bypasses all standard WordPress authentication checks, including nonce verification, capability checks, and password validation. If the hash matches, the function programmatically authenticates the request as a specified administrator account. Because the backdoor is hardcoded and no patch exists, remediation requires uninstalling the plugin or manually removing the `_arve_uc_init()` definition and its `add_action( 'init', '_arve_uc_init', 1 )` registration.

## Contribution

The advisory provides no upstream development timeline or review discussion; Wordfence PRISM identified the backdoor and attributed it to a compromised developer account, with no vendor patch or response documented.
