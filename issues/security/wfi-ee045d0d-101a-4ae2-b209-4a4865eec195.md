# Invoice Generator <= 1.0.0 - Unauthenticated Privilege Escalation via Account Takeover via 'user_id' Parameter

- **Usefulness:** 5/5

## Summary

The Invoice Generator plugin (≤ 1.0.0) contains a critical unauthenticated privilege escalation vulnerability that allows attackers to hijack any WordPress user account. The flaw stems from a missing capability check on the `pravel_invoice_edit_account()` AJAX handler, which accepts attacker-controlled `user_id` and `user_email` parameters and directly calls `wp_update_user()` without verifying authentication, ownership, or a nonce. This enables unauthenticated users to change any account's email address and subsequently trigger WordPress's native password reset flow to gain full access.

## Impact

- **Site owners & administrators**: Immediate risk of complete account takeover for any user, including administrators.
- **Plugin & theme developers**: No direct code changes required, but this highlights the importance of capability checks and nonce verification on all `wp_ajax_nopriv_*` endpoints.
- **Hosting & platform teams**: Monitor for exploitation attempts targeting the `pravel_invoice_edit_account` AJAX action and consider blocking or rate-limiting it if the plugin cannot be removed.
- **Required action**: The plugin has no known patch. Uninstalling Invoice Generator or disabling the affected AJAX endpoint is strongly recommended until a fixed version is released.

## Technical details

The vulnerability resides in the `pravel_invoice_edit_account()` function, which is registered as a public AJAX action via `wp_ajax_nopriv_pravel_invoice_edit_account`. The handler processes `$_POST['user_id']` and `$_POST['user_email']` and passes them directly to `wp_update_user()` without calling `current_user_can()`, verifying nonce tokens, or confirming that the requesting user owns the target account. Because the endpoint is exposed to unauthenticated requests, an attacker can craft a POST request to change any user's email address, then initiate WordPress's native password reset flow to hijack the account.
