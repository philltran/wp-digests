## Summary

Super Forms 6.3.314 patches a critical unauthenticated arbitrary file upload vulnerability present in versions up to 6.3.313. The flaw allowed attackers to bypass file type validation and capability checks on the `submit_form` AJAX handler, enabling remote code execution via two unauthenticated HTTP requests. Updating to 6.3.314 is required to close this attack vector.

## Impact

- **Site owners & administrators**: Update Super Forms to 6.3.314 immediately to prevent unauthenticated file uploads and potential remote code execution.
- **Plugin & theme developers**: No breaking changes, API deprecations, or migration steps; this is a security patch for the plugin itself.
- **Hosting & platform teams**: Monitor for exploitation attempts targeting the `submit_form` AJAX endpoint and ensure Super Forms is patched across all installations.
- **No action required** for custom code unless you were explicitly relying on the vulnerable `submit_form` nopriv handler for custom integrations (which is strongly discouraged).

## Technical details

The vulnerability resided in the `submit_form` function, specifically its `nopriv` AJAX handler, which lacked both capability checks and file type validation. Attackers could bypass the nonce requirement by first calling the `super_create_nonce` `nopriv` AJAX action to mint a valid `sf_nonce` and session cookie, then submitting a crafted request to `submit_form` using the `datauristring` or `value` parameters to upload arbitrary files. Version 6.3.314 resolves this by enforcing proper capability checks, validating uploaded file types, and tightening the nonce/session flow to prevent unauthenticated exploitation.
