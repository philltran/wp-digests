## Summary

The QA Assistants – Driven by data plugin contained an unauthenticated remote code execution flaw. An attacker without an account could execute code on the WordPress server. The vulnerability is fixed in the patched release.

## Impact

- **Site owners:** Update the plugin immediately; unauthenticated RCE can lead to full site compromise.
- **Plugin and theme developers:** If your product depends on this plugin, verify the patched release is installed and test any integration after updating.
- **Hosting and platform teams:** Patch all affected installations and review server logs for signs of exploitation.
- **Headless and REST consumers:** No API change is described, but the site should be treated as potentially compromised until patched.

## Technical details

The advisory identifies the issue as code injection that allows unauthenticated attackers to execute code on the server. It does not name the vulnerable function, endpoint, file, hook, or REST route. The remediation is to install the patched release; no code-level diff or API change is provided.
