# Realtyna Organic IDX plugin + WPL Real Estate <= 5.2.0 - Unauthenticated Arbitrary File Upload via 'files[file]' Parameter via Public I/O 'set_property' Command

## Summary

The Realtyna Organic IDX plugin + WPL Real Estate (≤ 5.2.0) contains an unauthenticated arbitrary file upload vulnerability that enables remote code execution. The flaw stems from a publicly registered I/O endpoint that lacks WordPress capability checks and accepts uploads via the `files[file]` parameter without validating file types. Attackers can exploit static, globally shared API credentials to bypass authentication entirely, making immediate mitigation or removal critical for affected installations.

## Impact

- **Plugin users & site owners**: Sites running Realtyna Organic IDX or WPL Real Estate ≤ 5.2.0 are directly exposed to unauthenticated remote code execution. No patch is available; the recommended action is to disable or uninstall the plugin immediately.
- **Hosting & platform teams**: Shared hosting environments running this plugin require server-side WAF rules or file upload restrictions to mitigate the risk until the plugin is removed.
- **No action required** for sites not using this specific plugin.

## Technical details

The plugin registers an I/O service endpoint on the `init` hook without any capability checks or nonce verification. The endpoint exposes a `set_property` command that processes the `files[file]` parameter for uploads. Authentication relies on static `api_key` and `api_secret` values seeded by the plugin’s SQL migration files, which are identical across all installations, effectively allowing unauthenticated access. The upload handler performs no file type or extension validation, permitting arbitrary executable files to be written to the server and enabling remote code execution.
