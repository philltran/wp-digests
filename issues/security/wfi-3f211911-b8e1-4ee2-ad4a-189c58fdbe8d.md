## Summary

The Authorizer plugin (<= 3.15.1) contains an unauthenticated privilege escalation vulnerability. Per the advisory, the plugin insufficiently restricts the capabilities a user can grant themselves, so an unauthenticated attacker can elevate their privileges beyond those intended for their role. The issue is fixed in 3.15.2.

## Impact

**Site owners**
- Any site running Authorizer 3.15.1 or earlier is exposed to a critical, unauthenticated attack (CVSS 9.8). Update to 3.15.2 or later as soon as possible.
- Because the advisory describes privilege escalation, treat affected sites as potentially compromised: review the user list for unexpected accounts or role changes (especially administrators) and rotate credentials if anything looks off.

**Plugin & theme developers / agencies**
- Audit client and managed sites for the Authorizer plugin and its installed version (e.g. `wp plugin list --name=authorizer`), and roll out the update.
- No API changes are documented; this is a security patch only.

**Hosting & platform teams**
- Consider flagging or force-updating Authorizer installs across fleets. The advisory does not describe a mitigating configuration, so patching is the remedy.
