## Summary

The WP BASE Booking of Appointments, Services and Events plugin has an unauthenticated remote code execution vulnerability in versions up to and including 6.3.0. An attacker can execute code on the server without authentication. The fix is to update to 6.3.1 or a newer patched version. Any site running a vulnerable version should be treated as potentially compromised.

## Impact

- **Site owners:** Update the plugin to 6.3.1 or later immediately if running <= 6.3.0; if the site was exposed, review for signs of compromise.
- **Agency and platform teams:** Audit all WordPress installs for the vulnerable plugin, force the update, and check for unexpected files, cron jobs, or user accounts.
- **Plugin and theme developers:** No API change is described; if custom code interacts with this plugin, verify it does not introduce its own code-injection path.
- **Headless and REST consumers:** No specific REST route or API change is disclosed; no action is required beyond updating the plugin.

## Technical details

The advisory provides no code-level detail: no vulnerable endpoint, function, file, hook, REST route, option, or payload is disclosed. It only states that unauthenticated attackers can execute code on the server. No before/after code pattern, schema change, or database change is provided.
