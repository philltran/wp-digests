# Solace Extra <= 1.6.0 - Missing Authorization to Unauthenticated Site Content Deletion and Unauthorized Demo Import via action-import-zip AJAX Action

- **Usefulness:** 5/5

## Summary

Solace Extra has a missing capability check on the `import_zip()` AJAX handler, allowing low-privilege users to delete site content and trigger demo imports. The handler is registered for both authenticated and unauthenticated AJAX requests and relies only on an `ajax-nonce` nonce that is exposed on admin pages. This can wipe navigation menus, sidebar widgets, theme mods, and Elementor templates. The patched release addresses the missing authorization.

## Impact

- **Site owners / administrators:** Update Solace Extra to the patched release immediately; affected versions are exposed to destructive content loss and unauthorized demo imports.
- **Plugin & theme developers:** If you build on Solace Extra or rely on its demo import, audit any custom code that calls or depends on the `action-import-zip` AJAX action; do not assume the nonce alone provides authorization.
- **Hosting & platform teams:** Treat this as a critical plugin vulnerability and prioritize patching; if immediate update is not possible, reduce exposure to admin pages and AJAX endpoints, though updating is the required fix.
- **Headless & REST consumers:** No REST route is described; the exposure is through the plugin's AJAX action, not a public REST endpoint.

## Technical details

The vulnerable code path is the `import_zip()` function behind the `action-import-zip` AJAX action. The handler is registered on both `wp_ajax_action-import-zip` and `wp_ajax_nopriv_action-import-zip`, and it only verifies the `ajax-nonce` nonce. That nonce is emitted on every admin page via `wp_localize_script` on an unrestricted `admin_enqueue_scripts` hook, making it available to authenticated users with Subscriber-level access and above. Successful exploitation can call destructive operations such as `update_option('sidebars_widgets', array())` and `remove_theme_mods()`, delete navigation menus and Elementor templates, and trigger arbitrary demo-content imports. The patched release addresses the missing authorization check.
