## Summary

The premium ACPT plugin, in all versions up to and including 2.0.63, lets unauthenticated attackers elevate their privileges because it does not sufficiently restrict the capabilities a user can grant themselves. The flaw is rated critical (CVSS 9.8). Wordfence lists no known patch.

## Impact

**Site owners**
- Any site running ACPT (Premium) <= 2.0.63 is exposed to unauthenticated privilege escalation, which can lead to full site takeover.
- No patched version is available. Wordfence's guidance is to assess risk and apply mitigations, and notes it may be best to uninstall the plugin and find a replacement.
- Review user accounts for unexpected privileged users (administrators or other elevated roles) and check for unexpected role or capability changes.

**Plugin & theme developers / agencies**
- Inventory client sites for ACPT (Premium) and check the installed version.
- If the plugin is in use, plan a removal or replacement. Content models built with it (custom post types, meta fields) would need migrating, so scope that early.
- Consider a WAF or virtual patching layer as an interim measure, but confirm coverage with your vendor; the advisory does not describe any specific rule.

**Hosting & platform teams**
- Search managed fleets for the plugin slug and versions <= 2.0.63 and flag affected sites.

**Headless & REST consumers**
- The advisory does not say which endpoint or entry point is affected, so headless setups using the plugin should be treated as exposed as well.

## Technical details

The advisory gives only a high-level description: the flaw is classified as CWE-269 (Improper Privilege Management) and stems from "insufficient restriction on the capabilities a user may grant themselves."
