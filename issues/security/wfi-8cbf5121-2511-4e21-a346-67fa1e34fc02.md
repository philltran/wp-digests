# WP Learn Manager <= 1.1.8 - Missing Authorization to Unauthenticated Arbitrary Plugin Installation and Activation via jslearnmanager_ajax AJAX Action

- **Usefulness:** 5/5

## Summary

The WP Learn Manager plugin (versions ≤ 1.1.8) contains a critical authorization bypass that allows unauthenticated attackers to install and activate arbitrary plugins via the `jslearnmanager_ajax` AJAX endpoint. This flaw stems from a missing capability check on the AJAX handler, effectively granting plugin management privileges to anyone with network access to the site. Site operators must treat this as an immediate security risk until a patch is released or the plugin is removed.

## Impact

- **Site owners & administrators**: Unauthenticated users can install and activate any plugin from the WordPress.org repository, potentially leading to full site compromise.
- **Plugin developers**: If you maintain WP Learn Manager, you must immediately add capability verification to the `jslearnmanager_ajax` handler or disable the endpoint.
- **Hosting & platform teams**: Monitor for anomalous plugin installation activity on sites running this plugin and consider blocking the AJAX endpoint at the WAF level.
- **Action required**: No official patch is available yet. The advisory recommends uninstalling the plugin or applying immediate mitigations based on your risk tolerance.

## Technical details

The `jslearnmanager_ajax` AJAX action handler processes incoming requests without verifying user authorization. This missing check allows unauthenticated callers to invoke the endpoint and trigger arbitrary plugin installation and activation from the WordPress.org repository. Remediation requires adding explicit capability verification to the AJAX callback or deregistering the action entirely.
