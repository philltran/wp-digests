# WP Social Media Login <= 1.0.6 - Authentication Bypass to Account Takeover

- **Source:** Wordfence Intelligence
- **Type:** Vulnerability
- **Published:** 2026-08-20
- **CVE:** [CVE-2026-77000](https://www.cve.org/CVERecord?id=CVE-2026-77000)
- **CVSS:** 9.8 (Critical)
- **CWE:** CWE-288: Authentication Bypass Using an Alternate Path or Channel
- **Affected:** WP Social Media Login (plugin) <= 1.0.6
- **Researchers:** Khaled Alenazi
- **Link:** [https://www.wordfence.com/threat-intel/vulnerabilities/id/a192d097-79f8-42ce-8941-5a7b9f2b2df6](https://www.wordfence.com/threat-intel/vulnerabilities/id/a192d097-79f8-42ce-8941-5a7b9f2b2df6)
- **Usefulness:** 5/5

## Summary

The WP Social Media Login plugin has an unauthenticated authentication bypass in its Twitter login flow, present in all versions up to and including 1.0.6. An attacker can log in as arbitrary existing users, including administrators, which amounts to full account takeover. No patched version is available.

## Impact

**Site owners**
- Any site running WP Social Media Login <= 1.0.6 is exposed to unauthenticated administrator-level takeover (CVSS 9.8, Critical).
- No patch exists. Wordfence's guidance is to weigh mitigations against your risk tolerance, and notes it may be best to uninstall the plugin and find a replacement.
- Because the flaw is in the Twitter login flow, the practical mitigation is to deactivate and remove the plugin. Review administrator accounts, recent logins, and any newly created users or changed credentials for signs of compromise.

**Plugin & theme developers / agencies**
- Audit client sites and managed fleets for this plugin and plan a replacement social-login solution.
- If you have custom code depending on this plugin's login endpoints or user-mapping behavior, it will need to be migrated.

**Hosting & platform teams**
- Consider flagging or blocking the plugin across hosted fleets, since exploitation requires no authentication.

## Technical details

The advisory record gives only high-level detail: the bug is classed as CWE-288 (Authentication Bypass Using an Alternate Path or Channel) and sits in the plugin's Twitter login flow. The flow can be abused by an unauthenticated attacker to be authenticated as another existing user, such as an administrator. The record does not identify the specific function, hook, endpoint, or parameter involved, and no patch or diff is available, so the exact root cause is not documented here.
