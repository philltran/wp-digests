- **Usefulness:** 5/5

## Summary

ARForms fixed an unauthenticated PHP object injection vulnerability caused by deserializing untrusted data from form submissions. The flaw allowed an attacker to submit crafted serialized object data, but exploitation requires a POP chain from another installed plugin or theme. The patched release addresses the unsafe deserialization path. Sites using the affected plugin should update promptly.

## Impact

- **Site owners / hosting & platform:** Update ARForms to the patched release; this is an unauthenticated critical-severity issue.
- **Plugin & theme developers:** If your code or dependencies provide a POP chain, the risk is elevated; audit deserialization sinks and avoid trusting serialized form data.
- **No action required** if already running the patched release.

## Technical details

The vulnerability is a deserialization of untrusted data issue in ARForms form-submission handling. An unauthenticated attacker could supply attacker-controlled serialized PHP object data through a form submission. The advisory states that no known POP chain exists in ARForms itself, so impact depends on another plugin or theme providing a POP chain. The patched release addresses the unsafe deserialization of untrusted input.
