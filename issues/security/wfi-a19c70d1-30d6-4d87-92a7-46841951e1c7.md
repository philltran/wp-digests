## Summary

Migratico Lite, a WordPress plugin, has an unauthenticated remote code execution vulnerability in all versions up to and including 2.6.8. User-supplied input is executed without sufficient validation, so an attacker needs no account to run arbitrary code on the server. The issue is fixed in 2.7.1.

## Impact

**Site owners / hosting & platform teams**
- Any site running Migratico Lite <= 2.6.8 is exposed to unauthenticated code execution (CVSS 9.8, Critical). Update to 2.7.1 or later immediately.
- If the plugin cannot be updated right away, deactivate and remove it until patched.
- Sites that ran a vulnerable version on a publicly reachable host should be treated as potentially compromised: review for unexpected files, admin users, scheduled events, and modified core/plugin files, and rotate credentials and salts if there is any sign of compromise.

**Plugin & theme developers / agencies**
- Audit client and managed sites for the plugin (e.g. `wp plugin list`) and confirm the installed version is >= 2.7.1.
- No API, hook, or configuration changes are documented in the advisory; the action is the version update.

## Technical details

The advisory classifies the flaw as CWE-94 (Improper Control of Generation of Code). It states only that the plugin executes user-supplied input without sufficient validation and that no authentication is required.

The record does not name the vulnerable endpoint, function, hook, or file, and it includes no diff or patch description. No specifics about the exploit path or the nature of the fix in 2.7.1 can be derived from the provided material.
