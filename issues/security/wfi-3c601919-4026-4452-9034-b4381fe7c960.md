## Summary

Aimogen Pro plugin versions ≤2.8.3 contained an unauthenticated arbitrary file upload vulnerability caused by missing file type validation. The issue has been resolved in version 2.8.3.1, which enforces strict type and extension checks before accepting uploads. This fix prevents attackers from uploading malicious files that could lead to remote code execution.

## Impact

- **Site owners & administrators**: Must update to 2.8.3.1 immediately to close an unauthenticated attack vector that could compromise the server.
- **Hosting & platform teams**: Monitor upload logs for Aimogen Pro endpoints and consider temporary WAF rules blocking dangerous extensions until patched.
- **Plugin & theme developers**: No direct API or hook changes; this is a vendor security patch.
- **Required action**: Update the plugin to 2.8.3.1 or later. No code modifications, configuration changes, or data migrations are required.

## Technical details

The vulnerability exists in the plugin’s upload ingestion logic, which previously accepted requests without verifying file extensions or MIME types. The patch in 2.8.3.1 introduces validation that rejects non-allowed file types before they are written to the filesystem. The advisory does not disclose specific internal file paths, REST routes, or hook names, but the fix operates at the upload handler layer to enforce type restrictions and prevent arbitrary file writes.
