# WS Form LITE <= 1.10.80 - Unauthenticated PHP Object Injection via Form Submission

- **Affected:** WS Form LITE – Drag & Drop Contact Form Builder (plugin) <= 1.10.80
- **Patched in:** 1.10.82

- **Usefulness:** 5/5

## Summary

WS Form LITE up to and including 1.10.80 deserializes untrusted input taken from form submission meta values, allowing unauthenticated attackers to inject arbitrary PHP objects (CWE-502). The plugin itself contains no known POP chain, so exploitability depends on another installed plugin or theme providing one. Version 1.10.82 fixes the issue.

## Impact

**Site owners**
- Update WS Form LITE to 1.10.82 or later. The vulnerable endpoint is reachable by unauthenticated visitors submitting a form, so any site running an affected version with a public form is exposed.
- On its own, the flaw has no impact because no POP chain exists in WS Form LITE. Risk becomes real when any other installed plugin or theme (including inactive-but-loadable code) supplies a usable gadget chain. Depending on that chain, outcomes can include arbitrary file deletion, sensitive data disclosure, or code execution.

**Plugin & theme developers / agencies**
- Audit client sites for WS Form LITE <= 1.10.80, particularly those that also run plugins with known gadget chains.
- No API changes or migration are described in the advisory; the fix is a plugin update.

**Hosting & platform teams**
- Consider prioritizing this in managed-update or virtual-patching workflows given the CVSS 9.8 rating and unauthenticated attack surface.

## Technical details

The advisory states that the plugin passes form submission meta values to a deserialization routine (e.g. `unserialize()`) without adequate validation, so attacker-supplied serialized strings submitted through a form become PHP objects. The record does not name the specific function, file, or code path, and no diff or patch details are provided, so how 1.10.82 changes the behavior (e.g. restricting `allowed_classes`, switching serialization format, or validating input) is not stated in the source.

Key characteristics per the record:
- Attack vector: unauthenticated form submission
- Weakness: CWE-502, Deserialization of Untrusted Data
- Affected: <= 1.10.80; fixed: 1.10.82
- No POP chain in WS Form LITE itself; exploitation requires a chain from another installed component
