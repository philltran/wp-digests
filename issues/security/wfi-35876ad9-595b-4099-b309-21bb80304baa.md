# WooCommerce File Approval <= 10.7 - Unauthenticated Arbitrary File Deletion

- **Affected:** WooCommerce File Approval (plugin) <= 10.7

- **Usefulness:** 5/5

## Summary

The WooCommerce File Approval plugin does not sufficiently validate file paths in all versions up to and including 10.7. Unauthenticated attackers can use this path traversal flaw to delete arbitrary files on the server. Deleting a file such as `wp-config.php` can lead to remote code execution, for example by forcing the site back into the installer flow. No patched version is available.

## Impact

**Site owners**
- Any site running WooCommerce File Approval <= 10.7 is exposed to unauthenticated attackers, with no login or special role needed.
- No patched release exists. The advisory recommends assessing risk and applying mitigations, and says it may be best to uninstall the plugin and find a replacement.
- Deleting `wp-config.php` is the example the advisory gives for how file deletion can escalate to remote code execution.

**Agencies / hosting & platform teams**
- Inventory client sites and fleets for this plugin and deactivate or remove it where it is present.
- A WAF rule or virtual patch may reduce exposure, but the record does not describe the vulnerable endpoint, so any rule would have to be written without knowing the exact request path.
- Ensure tested backups exist, since the impact of exploitation includes deletion of arbitrary files.

**Plugin & theme developers**
- No API changes. The takeaway is that user-supplied paths used in deletion routines need strict validation against an allowed base directory.
