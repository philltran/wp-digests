# Blocksy Companion Pro <= 2.1.46 - Unauthenticated Remote Code Execution

- **Source:** Wordfence Intelligence
- **Type:** Vulnerability

- **CVE:** [CVE-2026-57624](https://www.cve.org/CVERecord?id=CVE-2026-57624)
- **CVSS:** 9.8 (Critical)
- **CWE:** CWE-94: Improper Control of Generation of Code ('Code Injection')
- **Affected:** Blocksy Companion Pro (plugin) <= 2.1.46
- **Patched in:** 2.1.47
- **Researchers:** Nguyen Ba Khanh

- **Usefulness:** 5/5

## Summary

Blocksy Companion Pro versions up to 2.1.46 contain an unauthenticated remote code execution vulnerability that allows attackers to execute arbitrary code on the server. The issue was resolved in version 2.1.47, which patches the insecure input handling that previously allowed unauthenticated execution. Site administrators and developers using this companion plugin must update immediately to prevent exploitation.

## Impact

- **Site owners & administrators:** Update Blocksy Companion Pro to 2.1.47 or later immediately. Unpatched sites are vulnerable to full server compromise.
- **Plugin & theme developers:** If your theme or plugin bundles or depends on Blocksy Companion Pro, verify that your distribution ships with version 2.1.47+ or dynamically enforces the minimum version.
- **Hosting & platform teams:** Monitor for exploitation attempts targeting this plugin and ensure automated patching workflows prioritize this update.
- **Core WordPress developers:** No action required; this affects a third-party plugin, not the WordPress core codebase.

## Technical details

The advisory does not disclose specific file paths, functions, or REST routes involved in the vulnerability. The fix in version 2.1.47 addresses the insecure handling of unauthenticated requests that previously allowed arbitrary code execution. Developers should review their plugin dependency management and ensure that any bundled or required third-party components are updated to the patched version.
