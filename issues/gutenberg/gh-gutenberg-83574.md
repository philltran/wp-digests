## Summary

The Code block (`core/code`) now declares `dimensions.minWidth` and `dimensions.minHeight` in its `block.json` supports, enabling minimum-width and minimum-height controls in the block inspector and Global Styles. This closes a gap where the block already supported border, background, colour, shadow, spacing, and typography but lacked dimension controls, as part of the broader design-tools consistency effort tracked in #43241.

## Impact

- **Site owners / content editors:** Can now set a minimum width or height on Code blocks via the block inspector (Dimensions panel) or via Global Styles → Blocks → Code → Dimensions, including separate mobile values.
- **Plugin & theme developers:** No action required. The support is purely declarative in `block.json`; the Code block is a static block whose wrapper is produced by `useBlockProps.save()`, which serializes the dimension styles automatically. No PHP render callback or custom CSS is needed.
- **Headless / REST consumers:** No schema or route changes. The new values are stored as block attributes and rendered as inline styles on the wrapper element, same as any other dimension support.

## Technical details

The functional change is a single addition to `packages/block-library/src/code/block.json`:

```json
"dimensions": {
    "minHeight": true,
    "minWidth": true
}
```

Because `core/code` is a static block (no `render.php` or `render_callback`), the wrapper element is generated by `useBlockProps.save()`, which reads the `supports` declaration and emits the appropriate `wp-block-code` wrapper with inline `min-width` / `min-height` styles when the attributes are set. No rendering code, PHP, or CSS file was modified.

The remaining diff is documentation regeneration:
- `docs/reference-guides/core-blocks/README.md` — the Code block's supports list now includes `dimensions (minHeight, minWidth)`.
- `packages/block-library/src/code/README.md` — a new `dimensions` section lists `minHeight: true` and `minWidth: true`.

No new hooks, filters, REST schema fields, or database columns are introduced.
