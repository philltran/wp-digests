## Summary

The Term Name block (`core/term-name`) now supports margin via the `spacing.margin` block support. Previously it supported padding, border, background, colour, shadow, and typography but had no margin control, making it impossible to align consistently with the adjacent Term Description block (which already had margin) inside a Term Template. The change is a single `block.json` addition; no PHP or JS code changes are required because the block is server-rendered and its wrapper is produced by `get_block_wrapper_attributes()`, which serializes the support automatically.

## Impact

- **Block theme / site builder users:** Margin can now be set on the Term Name block via Global Styles (Blocks → Term Name → Dimensions) or the block inspector, with full responsive (mobile/desktop) support. No action required.
- **Plugin & theme developers:** No code changes needed. If you build custom term templates or extend the Term Name block, the new `spacing.margin` support is available automatically. No deprecated or removed APIs.
- **Hosting & platform:** No migration, configuration, or upgrade steps. The change is additive to `block.json` only.

## Technical details

The sole functional change is in `packages/block-library/src/term-name/block.json`, where the `spacing` support object gains a `margin` key:

```json
"spacing": {
    "padding": true,
    "margin": true
}
```

Because the block is server-rendered and its wrapper element is generated by `get_block_wrapper_attributes()`, the margin CSS custom properties (`--wp--style--block-gap`-style variables for margin) are serialized into the wrapper's `style` attribute automatically — no change to the render callback or any PHP file is needed.

The render callback returns an empty string when no term is present, so there is no risk of an empty wrapper element receiving margin and producing a visible gap.

Two documentation files are regenerated to reflect the new support:
- `docs/reference-guides/core-blocks/README.md` — the Term Name supports line changes from `spacing (padding)` to `spacing (margin, padding)`.
- `packages/block-library/src/term-name/README.md` — a `margin: true` bullet is added under the `spacing` section.
