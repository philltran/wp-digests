## Summary

The Post Terms block (`core/post-terms`) now supports `dimensions.minWidth` and `dimensions.minHeight`, enabling minimum-size controls in both Global Styles and the block inspector. This closes a gap where the block already supported border, background, colour, shadow, spacing, and typography but had no minimum-size controls, as part of the broader design-tools consistency effort tracked in #43241. Because the block is server-rendered and its wrapper is produced by `get_block_wrapper_attributes()`, the new support serialises automatically with no PHP-side change.

## Impact

- **Theme & pattern developers:** The Post Terms block now accepts `min-width` and `min-height` via Global Styles (including mobile breakpoints) and per-block overrides in the inspector. No code changes required; the support is opt-in through the existing style controls.
- **Site owners / editors:** New Dimensions controls appear under Global Styles → Blocks → Post Terms and in the block inspector. No migration or configuration needed.
- **Plugin & theme developers:** No breaking changes, no new hooks, no new REST fields. If you build custom Post Terms wrappers or patterns, the block's rendered wrapper may now carry `min-width`/`min-height` inline styles when a user sets them.
- **No action required** for existing sites; the support is additive and inert until a value is set.

## Technical details

The change is confined to `packages/block-library/src/post-terms/block.json`, where a new `dimensions` key is added to the `supports` object:

```json
"dimensions": {
    "minHeight": true,
    "minWidth": true
}
```

Because Post Terms is a server-rendered block whose wrapper is generated by `get_block_wrapper_attributes()`, the block-supports machinery serialises the `min-width` and `min-height` CSS custom properties into the wrapper's `style` attribute automatically. No change to `render.php` or any PHP file is needed.

The render callback returns an empty string when the post has no terms in the selected taxonomy, so no wrapper element is emitted and no empty minimum-size box can appear.

Two documentation files are regenerated to reflect the new support:
- `docs/reference-guides/core-blocks/README.md` — the Post Terms supports line now lists `dimensions (minHeight, minWidth)`.
- `packages/block-library/src/post-terms/README.md` — a new `dimensions` section with `minHeight: true` and `minWidth: true` is inserted between the `color` and `shadow` entries.
