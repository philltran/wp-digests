## Summary

The Accordion block now declares `color.link`, `color.heading`, and `color.button` in its `block.json` supports, exposing element-colour controls in the block inspector and Global Styles. Previously the block only offered background and gradient colours, even though links, headings, and buttons inside accordion panels already rendered with element colours on the front end via `lib/block-supports/elements.php`. This change brings the Accordion block in line with Group and Columns, which already expose the same element-colour controls, as part of the broader design-tools consistency effort tracked in #43241.

## Impact

- **Site builders / theme developers:** The Accordion block's Styles → Elements panel and the Global Styles → Blocks → Accordion → Elements section now show link, heading, and button colour pickers. No code or configuration changes are required; the controls appear automatically after updating to the release that includes this commit.
- **No action required** for existing sites. Element colours set on Accordion content already rendered on the front end before this change (the serialization path in `lib/block-supports/elements.php` does not gate on the `block.json` support flag). This PR adds the editing UI, not the rendering logic.
- **Heading colour scope:** The `color.heading` support also applies to the Accordion Heading titles, since they are heading elements rendered inside the block.

## Technical details

The functional change is confined to `packages/block-library/src/accordion/block.json`. The `supports.color` object gains three boolean keys:

```json
"color": {
  "background": true,
  "gradients": true,
  "link": true,
  "heading": true,
  "button": true
}
```

No PHP render-callback change is needed. The Accordion block's render callback uses `WP_HTML_Tag_Processor` solely to inject interactivity attributes; the saved `class` and `style` attributes on the block wrapper survive untouched, so the element-colour CSS generated by `lib/block-supports/elements.php` applies as before.

The remaining diff is documentation regeneration:
- `docs/reference-guides/core-blocks/README.md` — the Accordion supports line is updated from `color (background, gradients, text)` to `color (background, button, gradients, heading, link, text)`.
- `packages/block-library/src/accordion/README.md` — three new bullet entries for `link`, `heading`, and `button` under the `color` supports section.

The approach mirrors the earlier Columns change in #54104.
